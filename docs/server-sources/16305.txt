General Memory Population Rules and Guidelines: - Install DIMMs only if the corresponding processor is installed. If only one processor is installed in a 2-processor system, only half of the DIMM slots are available to populate. - If a memory channel consists of more than one DIMM slot, the white DIMM slot is located furthest from the CPU. White DIMM slots denote the first slot to be populated in a channel. For one DIMM per channel (DPC), populate white DIMM slots only. - Rank mixing is not allowed on a channel except for 1 rank + 2 rank combination when all 16 DIMMs for a Processor socket is populated. (2 rank in white slot, 1 rank in block slot), - No x4 mixing with x8 across a socket. - If multiple CPUs are populated, split the HPE Smart Memory DIMMs evenly across the CPUs and follow the corresponding CPU rules when populating DIMMs. - To maximize performance, it is recommended to balance the total memory capacity across all installed processors and load the channels similarly whenever possible. - If the number of DIMMs does not spread evenly across the CPUs, populate as close to evenly as possible. - Avoid creating an unbalanced configuration for any CPU. - The maximum memory capacity is a function of the number of DIMM slots on the platform-the largest DIMM capacity qualified on the platform and the number and model of qualified processors installed on the platform. - Do not mix HPE Smart Memory RDIMMs and HPE Smart Memory LRDIMMs in the same system. - Rank mixing is not allowed on a channel except for 1 rank + 2 rank combination (2 rank in white slot, 1 rank in block slot), when all 16 DIMMs for a Processor socket is populated. - The 256 GB 8R 3DS RDIMM can be mixed with 128 GB 4R 3DS RDIMM ONLY in 16 DIMMs populated. 256 GB 8R 3DS RDIMM needs to be in white slot while 128 GB 4R 3DS RDIMM needs to be in black slot. - The maximum memory speed is a function of the memory type, memory configuration, and processor model. - DIMMs of different speeds may be mixed in any order; however, the server will select the lowest common speed among all the DIMMs on all the CPUs. - HPE Smart Memory DIMMs and HPE NVDIMM-Ns from previous generation servers are not compatible with the current generation. Certain HPE Smart Memory features such as memory authentication and enhanced performance may not be supported. - There are no performance implications for mixing sets of different capacity DIMMs at the same operating speed. For example, latency and throughput will not be negatively impacted by installing an equal number of 32 GB 1rank x4 DDR5-4800 DIMMs (in block slot) and 64 GB 2rank x4 DDR5-4800 DIMMs (in white slot). - Take each DIMM type and create a configuration as if it were a homogeneous configuration. - For details on the HPE Server Memory Options Population Rules, visit: http://www.hpe.com/docs/memory-population-rules. - For additional information, refer to the HPE DDR5 Smart Memory QuickSpecs. Recommended Configurations for Acoustic Sensitive Environments For office-adjacent or low noise deployments, the ML110 Gen11 can maintain comparatively lower acoustic level when configured to minimize thermal load. The following guidance targets the main factors that could affect system fan speed and acoustic level of the platform. Recommended Storage Choices for Acoustic Considerations For environments where acoustic noise is a concern, we recommend using the Large Form Factor (LFF) drive cages as the primary storage configuration. LFF drives typically have lower thermal density and require less airflow for cooling compared to the more compact Small Form Factor (SFF) drive cages, resulting in reduced overall system noise. If SFF drive cage is necessary, limit the configuration to SATA SFF drives only. SATA drives generally operate more quietly than SAS drives, further minimizing acoustic output in sensitive environments. Hardware Options to Avoid for Acoustic-Sensitive Environments To minimize system acoustic level, avoid the following hardware options, as they tend to increase baseline system temperature and elevate acoustic level: - High-speed SAS storage drives: including SAS4, SAS 10K, and SAS 15K drives. - HPE NS204i-u OS Boot Device. - High-Capacity Memory Options: including 96GB DDR5 DIMMs. - Computation and Graphics Accelerators. - High-speed networking card (NIC): including NIC equal or greater than 100Gb. These options may require increased cooling, which could result in higher system fan speed and increased acoustic level. If High-Speed SAS Drives Are Unavoidable High-speed SAS drives generate additional thermal load and typically increase system fan speed and acoustic level. If these drives must be used, refer to the best practices outlined in the HPE customer advisory for ML110 Gen11. When configuring SFF SAS drives, install the drives in non-consecutive bays to improve airflow and reduce thermal load. For example: - In a 4-drive configuration, avoid using slots 1-4 consecutively; instead, use spaced installations such as slots 1, 4, 6, and 8 for better cooling. - In a 12-drive configuration, stagger drive placement (e.g., slots 1, 2, 4, 5, 7, and 8 in each box) to maintain airflow between drives. While this spacing approach can mitigate some of the thermal impact of high-speed SAS drives, it does not eliminate the underlying acoustic effects associated with higher-power storage devices.
